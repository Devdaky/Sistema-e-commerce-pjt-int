# VitaMarket - E-commerce de Modding e Tecnologia

O **VitaMarket** é um protótipo de e-commerce desenvolvido para a disciplina de Projeto Integrador de Programação Estruturada. O sistema simula a experiência de compras de periféricos e acessórios de modding de tecnologia por meio de uma interface em linha de comando (CLI).

## 🚀 Funcionalidades do Sistema
- **Navegação por Catálogo:** Consulta de produtos de tecnologia divididos por categorias e consulta por código/ID.
- **Detalhamento de Produtos:** Ficha técnica dos itens com preços e especificações de modding.
- **Carrinho de Compras:** Adição, alteração de quantidade, remoção de itens e cálculo automático do valor total.
- **Fluxo de Checkout:** Simulação de finalização da compra e esvaziamento do carrinho.

## 🛠️ Destaques Técnicos
- **Máquina de Estados:** Navegação fluida entre telas sem menus travados ou confusos.
- **Tratamento de Buffer:** Proteção contra erros de digitação do usuário (evita loops infinitos no terminal).
- **Multiplataforma:** Desenvolvido em C Puro (padrão ANSI C), compatível com Windows, Linux e macOS.
